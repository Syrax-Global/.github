| Path | What it is |
|---|---|
| `profile/README.md` | The organisation profile page at [github.com/Syrax-Global](https://github.com/Syrax-Global) |

| `NOTICE` | Ownership and terms of access |

## ⚠️ This repository is public

It exists so that the organisation profile renders, and so that anyone can find our security
contact and our ownership terms. **A GitHub organisation profile README is only shown when the
`.github` repository is public** — which is the whole reason this one is.

⛔ **Everything committed here is world-readable.** Only three kinds of content belong:
the profile page, the security policy, and the ownership notice. Internal engineering standards,
contributor guidance, templates and workflows live in the private repositories they apply to, and
their canonical copies are held internally.

## ⛔ Public-copy rules for `profile/README.md`

It is public company copy:

- **No regulator named in any sentence about Syrax**, and no second regulator named for balance.
- **No claim — direct or implied — that Syrax holds a licence or has applied for one.**
- **The payment platform is described as built and not yet offered to customers**, never as live
  or operational, for as long as that is the position.
- **No commercial counterparty named.**
- **No traction figures, user numbers or volumes that are not real.**
- **Protective and qualifying wording stays** — do not remove a sentence because it reads
  awkwardly; it is usually deliberate.

A change touching any of the above needs sign-off **before** it is merged, not after it is live.

## Security

See [`SECURITY.md`](SECURITY.md). Report privately to **info@syrax.global** — never in a public
issue, and never by pasting the credential you found.
